Drop .jpg / .png / .webp files in this folder to share images across all projects.

Naming convention:
Use snake_case matching the exercise name with underscores (_) instead of hyphens (-):
  "Seated Chest Press" -> images/seated_chest_press.jpg
  "Lat Pulldown"       -> images/lat_pulldown.jpg

The app will automatically pick them up by name across all workout plans!
